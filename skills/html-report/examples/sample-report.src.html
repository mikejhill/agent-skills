Content-defined boundaries move with the content, so an insert only invalidates the chunk it lands in. Fixed-size boundaries shift, so everything after the edit is new and gets re-hashed and re-stored.

Demo uses a FastCDC-style gear hash on characters at tiny chunk sizes. Dedup backup tools such as restic, borg and Kopia apply the same idea at file scale with multi-MiB average chunks.

Open questions

Q1 Why do 26 of 40 runs stay quiet?

Candidates: run length, concurrent CI jobs, cache churn since the last run. The 7-day trace can split alerting and quiet runs on each one.

Q2 Is the walk or the hashing the hot part?

If alerts track the number of changed bytes rather than file count, excluding the folder helps less than throttling the backup's parallelism.
