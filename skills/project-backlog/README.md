# project-backlog

Keeps a lightweight idea backlog and its specifications in `specs/` at the project root. Ideas start as short entries in `specs/project-backlog.md`, get promoted to `specs/<slug>/spec.md` for detailed design, and move to `specs/archive/` once done.

## Use

Loads automatically when you work with the backlog or a spec. Examples:

- "Add an idea for a CLI dashboard to the backlog."
- "Promote the centralized docs idea to a spec."
- "Archive the auth spec, it's shipped."

## Results

Files are written only under `specs/`. The backlog has no statuses or priorities; it is a list of ideas, not a task tracker.
